# Veta - Mantle Research Platform

> Premium AI-powered research platform for the Mantle ecosystem

## Features

- **Real-time Dashboard**: Live TVL, RWA metrics, ecosystem activity
- **AI Research Engine**: Evidence-based insights with structured outputs
- **Research Library**: Curated research papers and ecosystem analysis
- **Narrative Explorer**: Track capital flows and ecosystem themes

## Tech Stack

- **Frontend**: Next.js 14 (App Router), React 18, TailwindCSS
- **UI**: Geist fonts, Framer Motion animations
- **AI**: OpenAI API (GPT-4 reasoning)
- **Data**: Surf API, CoinGecko, DeFiLlama
- **State**: Zustand

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Project Structure

```
/app              - Next.js pages and layouts
/components       - Reusable React components
/lib              - Utilities and helpers
/services         - API integrations
/agents           - AI research engine
/data             - Static data and types
/styles           - Global styles
```
